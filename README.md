**STANFORD UNIVERSITY PHOTOGRAPHY CLUB WEBSITE**

This project is a static website built using HTML and CSS to represent the Stanford University Photography Club. It includes a homepage, events page, and members page, showcasing the club’s mission, activities, and upcoming events. The design is clean, responsive, and easy to navigate.

**PROJECT OVERVIEW**

The website features a welcoming homepage with a hero section, club mission, activity list, and meeting information. The events page highlights upcoming and past photography events, while the members page (to be developed) will showcase club participants. Semantic HTML and modular CSS are used throughout for clarity and maintainability.

**OBJECTIVES**

• Apply semantic HTML for structured content  
• Use CSS for styling and layout  
• Implement responsive design principles  
• Practice modular coding and clean formatting  
• Create a visually appealing and informative club website
